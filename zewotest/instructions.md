# Правила для этого проекта

- Язык: Python 3.14
- Все функции - с docstring
- Придерживаться PEP8, форматироваие через Black
- Не использивать print() для логиравания - только logging
- Комментарии в коде пиши на русском языке.
- Названия переменных и функций — на английском языке, в стиле camelCase.
- Не используй лишние библиотеки — если можно решить встроенными средствами языка, делай так.
- Код должен быть читаемым: избегай слишком длинных строк и сложных вложенных конструкций.
- Если есть ошибка или неоднозначность в задаче — сначала задай уточняющий вопрос, а не додумывай сам.
- Форматирование кода — отступы в 4 пробела (или 2, в зависимости от языка).
